Versión base del portfolio con HTML, CSS y JavaScript separados.

## Estructura

```text
PORTFOLIO/
├── index.html
├── styles.css
├── script.js
├── README.md
└── images/
```

## Ejecutar en localhost

Desde esta carpeta:

```bash
python -m http.server 5500
```

Luego abrir:

```text
http://localhost:5500
```

Para detener el servidor:

```text
Ctrl + C
```
